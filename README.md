## Key Features

- **Authentication & RBAC**: Secure JWT-based auth for Faculty, Students, Research Cell Officers, and System Admins.
- **Google Scholar SERP API Integration**: Native real-time profile sync, citation tracking, h-index, and i10-index calculation.
- **OpenAlex & Crossref Enrichment**: Automatic DOI validation, publisher verification, and open access metadata retrieval.
- **NAAC / NIRF Ready Report Engine**: 1-click custom CSV, HTML, and PDF report generator with interactive column reordering.
- **Research Data Auditor**: Automated 0-100% data health scoring, 20-issue taxonomy detection, safe auto-fix whitelist, and visual multi-source comparison matrix.

## Development Setup

To run the project locally, ensure you have Node.js (v18+) and npm installed.

```sh
git clone https://github.com/RoshanGaikwad2006/kriya-research-repo.git
cd kriya-research-repo
npm install

# Start frontend development server
npm run dev

# Start backend server
cd server
npm install
npm start
```
